# 生物统计学知识库资源建议

## 中文基础资源

1. 中国大学 MOOC：生物统计学
   - https://www.icourse163.org/course/detail.htm?cid=1452086221
   - 适合做中文知识库的基础章节结构参考。
   - 可覆盖：假设检验、参数估计、卡方检验、方差分析、回归与相关、试验设计。

2. 中国大学 MOOC：南京农业大学生物统计学
   - https://www.icourse163.org/course/detail.htm?cid=1001754031
   - 适合补充农业、生物实验设计相关例题。

3. 中国大学 MOOC：医学统计学
   - https://www.icourse163.org/course/detail.htm?cid=1452162258
   - 适合补充医学研究场景、临床资料分析和解释题素材。

4. 南京医科大学：医学统计学
   - https://www.icourse163.org/course/NJMU001-1001754254
   - 适合补充公共卫生和医学统计课程结构。

## 英文开放教材

1. OpenIntro：Introductory Statistics for the Life and Biomedical Sciences
   - https://www.openintro.org/book/biostat/
   - 有免费 PDF、章节练习、R lab 和教师资源，适合做基础统计知识库主干。

2. Handbook of Biological Statistics
   - https://www.biostathandbook.com/
   - 适合做“如何选择统计检验”的知识库，解释直观，面向生物学生。

3. Modern Statistics for Modern Biology
   - https://web.stanford.edu/class/bios221/book/
   - 适合做进阶模块，覆盖现代生物学中的统计建模、高通量数据、聚类、多变量分析等。

4. PH525x Biomedical Data Science
   - https://genomicsclass.github.io/book/
   - 适合补充 R、线性模型、高维数据、RNA-seq、甲基化等计算实践内容。

## 基因组与前沿扩展

1. Orchestrating Single-Cell Analysis with Bioconductor
   - https://bioconductor.org/books/release/OSCA/
   - 适合后续扩展单细胞 RNA-seq 分析知识库。

2. Bioconductor Books
   - https://bioconductor.org/books/
   - 适合定期扫描前沿生物信息学工作流教材。

3. PubMed
   - https://pubmed.ncbi.nlm.nih.gov/
   - 后续可按关键词、年份、期刊影响力和方法类型拉取文献摘要。

4. bioRxiv
   - https://www.biorxiv.org/
   - 适合获取前沿预印本，但进入教学知识库前需要额外标记“未经同行评议”。

## 后续知识库升级建议

1. 第一阶段：只录教材和课程大纲，保证基础概念稳定。
2. 第二阶段：加入教材配套例题、公开课程案例和 R/Python lab。
3. 第三阶段：加入综述论文、方法论文和高质量教程。
4. 第四阶段：让 Agent 自动区分资料类型：
   - textbook：稳定教材知识
   - lecture：课程材料
   - exercise：练习题/考试题
   - review：综述
   - paper：前沿论文
   - preprint：预印本
5. 第五阶段：为每个知识块记录难度、主题、适用学生层级、是否适合出题、是否适合生成课件。
